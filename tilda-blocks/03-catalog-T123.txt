=====================================================================
ЧАСТИНА 1. ІНСТРУКЦІЯ: ЯК ВСТАВИТИ КОД
=====================================================================

1. Відкрийте сторінку сайту в редакторі Tilda.
2. Натисніть "+" (Додати блок) -> розділ "Інше" -> блок T123
   ("HTML-код" / "Вставка HTML-коду").
3. Наведіть на блок і натисніть "Контент".
4. Скопіюйте ВЕСЬ код з ЧАСТИНИ 2: усе, що між рядками
   "ПОЧАТОК КОДУ" і "КІНЕЦЬ КОДУ" (самі ці рядки з "=====" копіювати
   НЕ потрібно).
5. Вставте код у поле і натисніть "Зберегти та закрити".
6. У режимі редагування Tilda показує T123 як сірий прямокутник
   "HTML-код". Це нормально - натисніть "Перегляд" або опублікуйте
   сторінку, щоб побачити блок.
7. Місце на сторінці: після блоку 02 (Переваги).
8. Якір (щоб кнопки з інших блоків прокручували сюди):
   наведіть на блок -> "Налаштування" -> поле "Якір для посилання" ->
   впишіть: catalog
   Посилання на цей блок з будь-якої кнопки: #catalog
8. Опублікуйте сторінку.

ВАЖЛИВО: щоб кнопка "У кошик" працювала, на цій же сторінці має
стояти блок 12 (Кошик). cartKey у цьому блоці і в блоці 12 мають
бути однакові (за замовчуванням вже однакові).

Усе редагується ТІЛЬКИ в об'єкті CONFIG на початку тегу <script>.
HTML і CSS чіпати не потрібно. Біля кожного параметра стоїть
коментар /* ЗМІНИТИ */.

kicker / title / lead - надписи над каталогом.

ТОВАРИ  ->  CONFIG.products
  Кожен товар - один рядок { ... }. Поля:
  id        - унікальний код латиницею (наприклад "pro-negative");
  name      - назва моделі;
  category  - "adult" або "kids" (для фільтра);
  cut       - "negative", "roll" або "hybrid" (для фільтра і мітки);
              "" - крій не вказано (модель видно тільки у фільтрі "Усі крої");
  price     - ціна числом без пробілів: 1650;
  oldPrice  - стара ціна (буде закреслена), 0 - не показувати;
  badge     - мітка на фото ("Хіт", "New", "-15%"), "" - без мітки;
  desc      - короткий опис;
  ratings   - оцінки для шкал від 0 до 10, наприклад [9.6, 9.8, 8.5]
              (порядок як у ratingLabels: Хват, Посадка, Зносостійкість);
              [] - без шкал;
  sizes     - доступні розміри, наприклад ["7","8","9"];
  image     - фото товару ("" = заглушка з іконкою рукавиці);
  image2    - друге фото, показується при наведенні (необов'язково);
  imagePosition - яку частину фото показувати в картці, "X% Y%"
              (для вертикальних фото рукавиць добре працює "50% 22%").

ФІЛЬТРИ  ->  categories, cuts
  Кнопки над товарами. id фільтра має збігатися з category / cut товару.
  Щоб прибрати фільтр за кроєм: cuts: []

ЯК ПРАЦЮЄ КОШИК
  Відвідувач обирає розмір -> "У кошик" -> точка "летить" у кнопку
  кошика (блок 12), лічильник збільшується. Без розміру кнопка
  трясе розміри і підсвічує "Оберіть розмір".
  Якщо в калькуляторі розмірів (блок 05) натиснути "Показати
  рукавиці мого розміру" - цей розмір автоматично обереться в усіх
  картках, де він є.

УВАГА: перші дві моделі (Synergy Evolution, Synergy Shine) - з реальними
фото, але ціна, оцінки, розміри і крій - заглушки. Решта моделей -
повністю ЗАГЛУШКИ.

  Доступні іконки (поле icon): drop, glove, shield, refresh, truck, ruler, star, water, wind, hand, bag, card, chat, box, clock, sun, target, x, check, arrow, plus, instagram, telegram, phone, mail, pin

---------------------------------------------------------------------
КОЛЬОРИ  ->  CONFIG.colors
---------------------------------------------------------------------
  Формат "#C8FF2E" або "rgba(200,255,46,0.35)" (останнє число -
  прозорість від 0 до 1). Кольори однакові в усіх блоках Synergy:
  якщо міняєте акцент - міняйте accent, accentHover, accentSoft і
  btnShadow в КОЖНОМУ блоці.
  Колір тексту в кнопках прописаний з !important, тому оранжевий колір
  посилань Tilda його не перебиває.

---------------------------------------------------------------------
ШРИФТИ І АНІМАЦІЇ
---------------------------------------------------------------------
  CONFIG.fonts - Unbounded (заголовки) + Manrope (текст), з кирилицею.
  settings.animations: false - вимкнути анімації в цьому блоці.
  Якщо в системі відвідувача ввімкнено "зменшити рух", анімації
  вимикаються самі.
