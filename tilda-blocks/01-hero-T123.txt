ЧАСТИНА 1. ІНСТРУКЦІЯ: ЯК ВСТАВИТИ КОД
=====================================================================

1. Відкрийте потрібну сторінку в редакторі Tilda.
2. Натисніть "+" (Додати блок) -> розділ "Інше" -> блок T123
   ("HTML-код" / "Вставка HTML-коду").
3. Наведіть на блок і натисніть "Контент".
4. Скопіюйте ВЕСЬ код з ЧАСТИНИ 2 - від рядка
   ===== ПОЧАТОК КОДУ =====
   до рядка
   ===== КІНЕЦЬ КОДУ =====
   (самі ці два рядки з "=====" копіювати НЕ потрібно).
5. Вставте код у поле і натисніть "Зберегти та закрити".
6. ВАЖЛИВО: у режимі редагування Tilda показує T123 як сірий
   прямокутник "HTML-код". Це нормально. Щоб побачити блок -
   натисніть "Перегляд" або опублікуйте сторінку.
7. Перетягніть блок на самий верх сторінки (одразу під меню).
8. Якщо у вас прозоре меню Tilda, яке лежить поверх першого екрану -
   у CONFIG змініть settings.topOffset (наприклад 80), щоб меню не
   перекривало логотип і текст.
9. Щоб кнопки "Обрати рукавиці" / "Підібрати розмір" прокручували
   до потрібних блоків:
   - відкрийте "Налаштування" потрібного блоку (каталог, таблиця
     розмірів);
   - у полі "Якір для посилання" впишіть, наприклад, catalog або size;
   - у CONFIG посилання вже стоять як "#catalog" та "#size".
10. Опублікуйте сторінку.

Фото і логотип:
   Фото власника бренду і логотип уже лежать на GitHub, посилання на
   них прописані в CONFIG - блок працює одразу після вставки.
   Якщо захочете тримати фото на Tilda (або замінити на інше):
   - Додайте на будь-яку сторінку тимчасовий блок із зображенням
     (наприклад IM01), завантажте фото.
   - Відкрийте "Перегляд", натисніть на фото правою кнопкою миші ->
     "Копіювати адресу зображення" (посилання буде виду
     https://static.tildacdn.com/...).
   - Вставте це посилання в CONFIG -> photo.desktop / photo.mobile
     (або logo.image для логотипу).
   - Тимчасовий блок можна видалити.
   Для ПК підходить квадратне або горизонтальне фото, де людина
   по центру. Для телефону - вертикальне фото, обличчя у верхній
   третині.

=====================================================================
ЧАСТИНА 3. ЩО І ДЕ ЗМІНЮВАТИ В ЦЬОМУ БЛОЦІ
=====================================================================

Усе редагується ТІЛЬКИ в об'єкті CONFIG на початку тегу <script>.
HTML і CSS чіпати не потрібно. Біля кожного параметра стоїть
коментар /* ЗМІНИТИ */.

Правила редагування:
  - змінюйте лише те, що в лапках "..." або числа;
  - не видаляйте коми в кінці рядків;
  - апостроф (м'яч, з'являється) можна писати як є - тексти взяті
    в подвійні лапки;
  - НЕ використовуйте емодзі - Tilda покаже їх як знаки питання.

---------------------------------------------------------------------
1. ФОТО  ->  CONFIG.photo
---------------------------------------------------------------------
  mode             - "panel": на ПК фото праворуч у панелі зі скошеним
                     краєм (як штрих у логотипі S) і лаймовою лінією;
                     на телефоні фото зверху, текст під ним.
                     "full": фото на весь екран під текстом.
  desktop          - фото для комп'ютера (зараз - власник у червоному,
                     видно рукавиці).
  mobile           - фото для телефону (зараз - вертикальне з прапором).
  positionDesktop  - яку частину фото видно на ПК, формат "X% Y%":
                     "50% 0%" = по центру, притиснуто до верху.
  positionMobile   - те саме для телефону. Якщо обличчя обрізається -
                     зменшуйте друге число ("50% 0%"), якщо треба нижче -
                     збільшуйте ("50% 30%").

  ПОЗНАЧКИ НА ФОТО  ->  CONFIG.hotspots / hotspotsMobile
  Лаймова пульсуюча точка з підписом (зараз - на рукавиці).
  x, y  - місце на самому фото від 0 до 1 (0.5 = середина,
          y: 0 = верх, 1 = низ). Точка "прилипає" до цього місця на
          будь-якому екрані.
  label - підпис; link - куди веде клік; side - з якого боку підпис.
  Якщо міняєте фото - підберіть x і y заново або зробіть список
  порожнім: hotspots: []

---------------------------------------------------------------------
2. ЛОГОТИП І INSTAGRAM  ->  CONFIG.logo, CONFIG.instagram
---------------------------------------------------------------------
  logo.image              - круглий логотип S (вже вставлений).
  logo.showText           - true = поруч ще й напис "SYNERGY GK".
  logo.text / logo.accent - текст напису (друга частина - акцентом).
  instagram.link          - порожнє "" - кнопка Instagram зникне.
  Якщо у вас вже є меню Tilda зі своїм логотипом - вимкніть цю панель:
  settings.showTopBar: false

---------------------------------------------------------------------
3. ТЕКСТИ  ->  badge, title, subtitle
---------------------------------------------------------------------
  badge     - маленька плашка з пульсуючою крапкою над заголовком.
  title     - заголовок, кожен рядок окремим пунктом. Можна залишити
              2 або додати 4 рядки (копіюйте рядок разом з комою).
              accent: true - рядок буде акцентного кольору і з
              намальованим підкресленням.
  subtitle  - опис під заголовком.

---------------------------------------------------------------------
4. КНОПКИ  ->  button1, button2
---------------------------------------------------------------------
  text   - напис;  link - посилання ("#catalog" - якір блоку на
  сторінці, або повне посилання https://...);  newTab - true, щоб
  відкривати в новій вкладці.
  button2.text порожнє "" - друга кнопка сховається.
  Колір тексту кнопок вже прописаний з !important, тому
  оранжевий колір посилань Tilda його не перебиває.

---------------------------------------------------------------------
5. ЦИФРИ  ->  stats
---------------------------------------------------------------------
  value  - якщо тут лише цифри ("1500"), число красиво "набігає"
           від 0. Якщо текст ("5-11") - просто з'являється.
  suffix - маленький текст після числа (мм, днів, +).
  label  - підпис під числом.
  УВАГА: зараз тут приклади. Обов'язково впишіть реальні дані
  клієнта (товщина латексу, умови обміну, кількість клієнтів).

---------------------------------------------------------------------
6. КАРТКА "МОДЕЛЬ СЕЗОНУ"  ->  card
---------------------------------------------------------------------
  label, tag, name - надписи; tag "" - мітка NEW зникне.
  chips            - короткі характеристики-"таблетки".
  bars             - шкали характеристик: value 0-100 - довжина
                     смужки, text - цифра праворуч (можна "10/10").
  price            - ціна; buttonLink - куди веде кнопка картки.
  Зараз картка вимкнена (settings.showCard: false), бо в режимі
  "panel" праворуч стоїть фото. Увімкнути: settings.showCard: true
  (на ПК вона стане в нижньому правому куті поверх фото).

---------------------------------------------------------------------
7. ФОНОВІ ДЕТАЛІ
---------------------------------------------------------------------
  bigWord           - величезне контурне слово на фоні ("" - прибрати).
  marquee           - фрази бігучого рядка внизу (можна додавати
                      та видаляти).
  scrollHint        - підказка "Гортай" (видно лише на ПК і лише в
                      режимі photo.mode: "full").

---------------------------------------------------------------------
8. КОЛЬОРИ  ->  CONFIG.colors
---------------------------------------------------------------------
  Формат: "#C8FF2E" або "rgba(200,255,46,0.35)" (останнє число -
  прозорість від 0 до 1).
  Головне:
    accent / accentHover - лаймовий акцент (кнопка, слово, шкали,
                           бігучий рядок). Щоб змінити стиль - міняйте
                           accent, accentHover, btnIconColor,
                           btnShadow, glow і marqueeBg разом.
    btnText              - текст на лаймових кнопках.
    bg                   - основний фон.
    overlay / overlaySoft / overlayMobile - сила затемнення фото.
                           Якщо фото світле і текст погано видно -
                           збільште останнє число (наприклад 0.95).
    text / textMuted     - кольори тексту.
    ghost...             - друга прозора кнопка.
    card... / cardBtn... - скляна картка та її кнопка.
    net                  - візерунок "воротарська сітка" праворуч.
  Готові альтернативні пари акценту (accent / accentHover):
    помаранчевий воротарський: "#FF6B1A" / "#F25A05"
    електрик синій:            "#2E7BFF" / "#1A66EB"  (btnText - "#FFFFFF")
    неоновий рожевий:          "#FF2E88" / "#EB1A74"  (btnText - "#FFFFFF")

---------------------------------------------------------------------
9. ШРИФТИ  ->  CONFIG.fonts
---------------------------------------------------------------------
  Зараз: Unbounded (заголовки, спортивний широкий) + Manrope (текст),
  обидва з кирилицею. Щоб змінити - візьміть посилання на Google
  Fonts і впишіть точні назви шрифтів у heading та body.

---------------------------------------------------------------------
10. НАЛАШТУВАННЯ  ->  CONFIG.settings
---------------------------------------------------------------------
  fullScreen      - true = блок на весь екран.
  topOffset       - відступ зверху для прозорого меню Tilda (px).
  animations      - false = вимкнути ВСІ анімації.
  photoZoom       - повільне наближення фото.
  parallax        - рух шарів за мишкою.
  cursorGlow      - світло за курсором.
  cardTilt        - 3D-нахил картки.
  accentUnderline - намальоване підкреслення під акцентним рядком.
  show...         - показати/сховати окремі елементи.
  marqueeSpeed    - швидкість бігучого рядка (секунди на коло).

---------------------------------------------------------------------
МІКРО-АНІМАЦІЇ В БЛОЦІ
---------------------------------------------------------------------
  - поява фото, рядки заголовка "виїжджають" знизу по черзі;
  - підкреслення акцентного рядка малюється лінією;
  - пульсуюча крапка в плашці;
  - "відблиск" пробігає по головній кнопці, стрілка повертається
    при наведенні;
  - лічильники цифр, шкали в картці заповнюються;
  - лаймова лінія вздовж скошеного краю фото "малюється" зверху вниз;
  - пульсуюча позначка на рукавиці з'являється з пружинкою;
  - логотип злегка повертається при наведенні;
  - картка (якщо увімкнена) плавно "парить", 3D-нахил за мишкою;
  - фото повільно наближається, на ПК шари рухаються за курсором,
    за курсором іде м'яке світло;
  - бігучий рядок (зупиняється при наведенні);
  - анімована "мишка" прокрутки.
  На телефонах і планшетах важкі ефекти (паралакс, нахил, світло)
  автоматично вимкнені, а якщо в системі користувача ввімкнено
  "зменшити рух" - анімації вимикаються самі.
