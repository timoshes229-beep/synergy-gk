=====================================================================
ЧАСТИНА 1. ІНСТРУКЦІЯ: ЯК ВСТАВИТИ КОД
=====================================================================

1. Відкрийте сторінку сайту в редакторі Tilda.
2. Натисніть "+" (Додати блок) -> розділ "Інше" -> блок T123
   ("HTML-код" / "Вставка HTML-коду").
3. Наведіть на блок і натисніть "Контент".
4. Скопіюйте ВЕСЬ код з ЧАСТИНИ 2: усе, що між рядками
   "ПОЧАТОК КОДУ" і "КІНЕЦЬ КОДУ" (самі ці рядки з "=====" копіювати
   НЕ потрібно).
5. Вставте код у поле і натисніть "Зберегти та закрити".
6. У режимі редагування Tilda показує T123 як сірий прямокутник
   "HTML-код". Це нормально - натисніть "Перегляд" або опублікуйте
   сторінку, щоб побачити блок.
7. Місце на сторінці: після блоку 06 (Засновник), перед блоком 07 (В грі). Можна поставити будь-де.
8. Якір (щоб кнопки з інших блоків прокручували сюди):
   наведіть на блок -> "Налаштування" -> поле "Якір для посилання" ->
   впишіть: play
   Посилання на цей блок з будь-якої кнопки: #play
8. Опублікуйте сторінку.

ВАЖЛИВО ПРО ПРОМОКОД: код у цьому блоці (CONFIG.promoCode) має
бути вписаний і в блоці 12 (Кошик) у списку promoCodes - з тим
самим відсотком знижки. Інакше кошик код не прийме.
За замовчуванням в обох блоках вже стоїть однаковий код SAVE10.

      ctx.font = "800 " + Math.round(Math.max(20, W * 0.03)) + "px " + getComputedStyle(root).getPropertyValue("--sgk-font-h");
      ctx.textAlign = "center"; ctx.fillStyle = w.c;
      ctx.fillText(w.t, w.x, w.y - (1 - w.life) * 40);
    });
    ctx.globalAlpha = 1;
    ctx.restore();
  }

  function frame(now) {
    raf = null;
    if (!state.playing || !visible) return;
    var dt = Math.min(50, now - (last || now)); last = now;
    glove.x += (glove.tx - glove.x) * 0.35; glove.y += (glove.ty - glove.y) * 0.35;
    glove.rot = Math.max(-0.35, Math.min(0.35, (glove.tx - glove.x) * 0.01));
    glove.sq = Math.max(0, glove.sq - dt / 260);
    shake = Math.max(0, shake - dt / 350); netJit = Math.max(0, netJit - dt / 400);
    if (!ball || (ball.done && now >= nextAt && state.lives > 0)) { if (!ball || now >= nextAt) shoot(now); }
    if (ball && !ball.done) {
      var t = Math.min(1, (now - ball.t0) / ball.dur), e = t * t * (3 - 2 * t) * 0.35 + t * 0.65, u = 1 - e;
      ball.x = u * u * ball.sx + 2 * u * e * ball.cx + e * e * ball.tx;
      ball.y = u * u * ball.sy + 2 * u * e * ball.cy + e * e * ball.ty;
      var r0 = H * 0.11, r1 = Math.max(12, H * 0.034);
      ball.r = r0 + (r1 - r0) * e; ball.rot += dt * 0.012;
      if (t >= 1) resolve(now);
    }
    particles = particles.filter(function (p) { p.x += p.vx; p.y += p.vy; p.vy += 0.25; p.life -= dt / 700; return p.life > 0; });
    words = words.filter(function (w) { w.life -= dt / 900; return w.life > 0; });
    draw(now);
    raf = requestAnimationFrame(frame);
  }

  /* --- керування --- */
  function point(e) {
    var r = arena.getBoundingClientRect(), p = e.touches ? e.touches[0] : e;
    glove.tx = Math.max(G.x - 10, Math.min(G.x + G.w + 10, p.clientX - r.left));
    glove.ty = Math.max(G.y + gloveH * 0.3, Math.min(G.y + G.h + gloveH * 0.2, p.clientY - r.top + (e.touches ? -gloveH * 0.35 : 0)));
  }
  arena.addEventListener("pointermove", function (e) { if (state.playing) point(e); });
  arena.addEventListener("pointerdown", function (e) { if (state.playing) point(e); });
  arena.addEventListener("touchmove", function (e) { if (state.playing) { point(e); e.preventDefault(); } }, { passive: false });
  arena.addEventListener("touchstart", function (e) { if (state.playing) { point(e); } }, { passive: true });

  function start() {
    resize();
    state.playing = true; state.score = 0; state.lives = LIVES; state.combo = 0;
    ball = null; particles = []; words = [];
    glove.x = glove.tx = W / 2; glove.y = glove.ty = G.y + G.h * 0.6;
    nextAt = 0; last = 0;
    updateHud();
    q("ovStart").classList.remove("is-on"); q("ovEnd").classList.remove("is-on");
    arena.classList.add("is-play");
    if (!raf) raf = requestAnimationFrame(frame);
  }
  function end() {
    state.playing = false; arena.classList.remove("is-play");
    var b = getBest(); if (state.score > b) setBest(state.score);
    showBest();
    var won = state.score >= (CONFIG.goal || 10) || getBest() >= (CONFIG.goal || 10);
    var left = Math.max(0, (CONFIG.goal || 10) - state.score);
    rich(q("endTitle"), (state.score >= (CONFIG.goal || 10) ? CONFIG.winTitle : CONFIG.loseTitle).replace("{n}", state.score));
    txt("endText", state.score >= (CONFIG.goal || 10) ? CONFIG.winText : CONFIG.loseText.replace("{left}", left));
    q("codeBox").classList.toggle("is-on", won);
    q("ovEnd").classList.add("is-on");
  }
  q("play").addEventListener("click", start);
  q("again").addEventListener("click", start);

  function copy(t, cb) {
    try { if (navigator.clipboard && window.isSecureContext) { navigator.clipboard.writeText(t).then(cb, cb); return; } } catch (e) {}
    var ta = document.createElement("textarea"); ta.value = t; ta.style.position = "fixed"; ta.style.top = "-1000px"; document.body.appendChild(ta); ta.select();
    try { document.execCommand("copy"); } catch (e) {}
    document.body.removeChild(ta); cb();
  }
  q("copy").addEventListener("click", function () { copy(CONFIG.promoCode, function () { toast(CONFIG.copiedToast); }); });
  q("apply").addEventListener("click", function () {
    try { window.localStorage.setItem(PROMO_KEY, CONFIG.promoCode); } catch (e) {}
    window.__sgkPromo = CONFIG.promoCode;
    try { document.dispatchEvent(new CustomEvent("sgk:promo", { detail: { code: CONFIG.promoCode } })); } catch (e) {}
    toast(CONFIG.appliedToast);
  });

  if ("IntersectionObserver" in window) {
    new IntersectionObserver(function (es) { es.forEach(function (e) { visible = e.isIntersecting; if (visible && state.playing && !raf) { last = 0; raf = requestAnimationFrame(frame); } }); }, { threshold: 0.2 }).observe(arena);
  }
  window.addEventListener("resize", function () { resize(); });
  gloveImg.onload = function () { if (!state.playing) draw(0); };
  ballImg.onload = function () { if (!state.playing) draw(0); };
  resize();
  glove.x = glove.tx = W / 2; glove.y = glove.ty = G.y + G.h * 0.62;
  updateHud();
  draw(0);

  reveal();

})();
</script>

=====================================================================
ЧАСТИНА 3. ЩО І ДЕ ЗМІНЮВАТИ В ЦЬОМУ БЛОЦІ
=====================================================================

Усе редагується ТІЛЬКИ в об'єкті CONFIG на початку тегу <script>.
HTML і CSS чіпати не потрібно. Біля кожного параметра стоїть
коментар /* ЗМІНИТИ */.

ЯК ГРАЄТЬСЯ
  Натискаєш "Грати" - у ворота летять м'ячі (спершу повільно, потім
  все швидше). Рукавиця слідує за мишкою або пальцем. Зловив -
  лаймовий вибух і напис "Сейв!", пропустив - "Гол!", сітка
  тремтить, мінус життя. Після 3 пропущених - фінал.
  Зверху: рахунок сейвів, смужка "до знижки" і життя.
  Набрав потрібну кількість сейвів (goal) - відкривається промокод:
  "Застосувати в кошику" (код сам підставиться в кошик, блок 12)
  або "Скопіювати". Рекорд гравця запам'ятовується в його браузері.

ПРОМОКОД
  goal       - скільки сейвів треба (10);
  promoCode  - сам код (SAVE10). ТАКИЙ САМИЙ код з тим самим %
               має бути в блоці 12 (Кошик) -> promoCodes;
  promoText  - що дає код.
  Промокод - чесна знижка: у замовленні буде видно код і суму
  знижки, ви бачите це в повідомленні і підтверджуєте.

СКЛАДНІСТЬ  ->  settings
  lives      - скільки можна пропустити (3);
  startSpeed - час польоту першого м'яча (1.35 с, більше = легше);
  minSpeed   - найшвидший політ (0.55 с).

ТЕКСТИ - усі написи гри в CONFIG (start..., win..., lose...,
  saveWords - випадкові написи після сейву).

  Доступні іконки (поле icon): drop, glove, shield, refresh, truck, ruler, star, water, wind, hand, bag, card, chat, box, clock, sun, target, x, check, arrow, plus, instagram, telegram, phone, mail, pin

---------------------------------------------------------------------
КОЛЬОРИ  ->  CONFIG.colors
---------------------------------------------------------------------
  Формат "#C8FF2E" або "rgba(200,255,46,0.35)" (останнє число -
  прозорість від 0 до 1). Кольори однакові в усіх блоках Synergy:
  якщо міняєте акцент - міняйте accent, accentHover, accentSoft і
  btnShadow в КОЖНОМУ блоці.
  Колір тексту в кнопках прописаний з !important, тому оранжевий колір
  посилань Tilda його не перебиває.

---------------------------------------------------------------------
ШРИФТИ І АНІМАЦІЇ
---------------------------------------------------------------------
  CONFIG.fonts - Unbounded (заголовки) + Manrope (текст), з кирилицею.
  settings.animations: false - вимкнути анімації в цьому блоці.
  Якщо в системі відвідувача ввімкнено "зменшити рух", анімації
  вимикаються самі.

---------------------------------------------------------------------
ЗАГАЛЬНІ ПРАВИЛА
---------------------------------------------------------------------
  - Змінюйте тільки значення в лапках "..." та числа, коми не видаляйте.
  - Слово в [квадратних дужках] у заголовках стає акцентного кольору.
  - НЕ використовуйте емодзі - Tilda покаже їх як знаки питання.
  - Порожнє фото "" = красива заглушка з іконкою. Коли будуть фото
    від клієнта - вставте посилання на них (як отримати посилання з
    Tilda - див. блок 01, частина 1).
